# Azure Haven Hotel - Luxury Beachfront Landing Page

A complete, production-quality landing page for the fictional Azure Haven Hotel, built as an AI agent benchmark project.

## Project Description

This project implements a luxury hotel landing page for Azure Haven Hotel, a fictional beachfront boutique hotel. The implementation demonstrates professional frontend development using only HTML5, CSS3, and vanilla JavaScript.

## Technology Used

- **HTML5** - Semantic markup and accessibility
- **CSS3** - Modern styling with responsive design
- **Vanilla JavaScript** - Interactive functionality and UX enhancements

No frontend frameworks or libraries were used (no React, Vue, Angular, Bootstrap, jQuery, etc.).

## How to Run

1. Clone or download the project files
2. Open `index.html` in a modern web browser
3. The page is fully functional locally - no build process required

## Design Decisions

### Visual Style
- **Direction**: Modern luxury, minimal, editorial, premium
- **Color Palette**: Ocean blues, warm neutrals, premium golds
- **Typography**: Clean, readable sans-serif hierarchy
- **Layout**: Content-focused with strategic whitespace

### Responsive Breakpoints
- **Desktop**: 1440px+ - Full experience
- **Laptop**: 1024px-1439px - Optimized layout
- **Tablet**: 768px-1023px - Touch-friendly interface
- **Mobile**: 320px-767px - Streamlined mobile experience

### Accessibility Implementation
- Semantic HTML5 structure
- Proper heading hierarchy
- Alt attributes for all images
- ARIA labels and roles
- Keyboard navigation support
- Focus states for interactive elements
- High contrast ratios

## Performance Optimizations

- Lazy-loaded non-critical images
- Efficient CSS with reusable classes
- Minimal JavaScript for essential interactions
- Optimized image formats
- No external dependencies or frameworks
- Smooth animations using CSS transforms

## Known Limitations

- Booking form is frontend-only (no backend integration)
- Map location is a placeholder (requires API integration)
- Images are placeholders (requires professional hotel photography)
- No real-time availability checking
- No multi-language support
